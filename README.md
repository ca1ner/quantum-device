# Quantum Device

[Скачать Quantum Device для Windows](https://github.com/ca1ner/quantum-device/releases/latest/download/QuantumDevice.exe)

Показывает экран Android-телефона в окне Windows 10/11 x64. Для запуска нужен один файл.

1. Включи отладку по USB на телефоне и подключи его к ПК кабелем с передачей данных.
2. Открой **QuantumDevice.exe** на ПК. Если на телефоне появится запрос «Разрешить отладку по USB?», нажми «Разрешить».
3. Открой ленту на телефоне. Щёлкни по окну Quantum Device на ПК и листай колёсиком мыши или стрелками ↑ и ↓.
